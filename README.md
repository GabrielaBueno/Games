
# 🧠 Projetos da Imersão Dev - Alura

Este repositório reúne os projetos desenvolvidos durante a **Imersão Dev da Alura**, realizada entre os dias **31 de março e 04 de abril de 2025**.

Durante essa semana intensa, mergulhei no universo da programação com **JavaScript**, criando cinco jogos interativos com foco em lógica, estruturas de dados e interatividade.

---

## 📌 Objetivo

Criar aplicações web divertidas e funcionais que consolidem os fundamentos da programação através de jogos clássicos e desafios criativos.

Cada projeto foi desenvolvido com HTML, CSS e JavaScript, utilizando uma abordagem prática e acessível para quem está iniciando na área.

---

## 🧠 Conhecimentos aplicados

- Variáveis, operadores e entrada de dados
- Condicionais (`if/else`)
- Funções e escopos
- Loops (`for`, `while`)
- Arrays e manipulação de dados
- Objetos e estruturação de conteúdo
- JSON e lógica de quiz
- Manipulação do DOM com JavaScript
- Interatividade e lógica de jogos

---

## 🖥️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- CodePen (ambiente de desenvolvimento online)

---

## 🔎 Projetos

### 🪙 Conversor de Moedas  
Conversor de Won para Real e Dólar utilizando entrada de dados e operações matemáticas.  
🔗 [Visualizar no CodePen](https://lnkd.in/d5UPD49n)

### ✊ Pedra, Papel e Tesoura  
Jogo interativo contra a máquina, com lógica condicional e números aleatórios.  
🔗 [Visualizar no CodePen](https://lnkd.in/dtFfxpWH)

### 🪟 Salto na Ponte de Vidro  
Jogo de escolhas baseado em loops e decisões progressivas.  
🔗 [Visualizar no CodePen](https://lnkd.in/d5ygMxPi)

### 💪 Cabo de Guerra  
Desafio entre times, com lógica de pontuação e manipulação de arrays.  
🔗 [Visualizar no CodePen](https://lnkd.in/d6Kb5Tmc)

### 🧠 Quiz Interativo  
Jogo de perguntas e respostas com uso de JSON, pontuação e feedback.  
🔗 [Visualizar no CodePen](https://lnkd.in/dAFNBNg5)

## ▶️ Como executar os projetos

Você pode clonar o repositório e abrir os arquivos `.html` de cada projeto diretamente no navegador:

```bash
git clone https://github.com/GabrielaBueno/Games.git
cd Games
```

Ou acessar os projetos diretamente pelo CodePen nos links indicados acima.
